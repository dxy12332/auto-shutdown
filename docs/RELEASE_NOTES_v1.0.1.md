## 定时关机 v1.0.1

功能与 v1.0.0 相同，这是一个修复版本。

### 修复的问题

**「立即取消关机」无法取消「每天重复」**

设了「每天 23:59 关机」之后，点主界面上的「立即取消关机」毫无反应——界面状态纹丝不动。原因是程序只清掉了一次性定时，**「每天重复」那条规则从来没有被取消过**。

已修复：现在两种定时会一起清除。

**界面上「每天」复选框不同步**

即使配置已经取消了，那个复选框仍停留在勾选状态，让人以为操作没生效。现在会同步回到未勾选。

**日志会误导排查**

原日志不管实际结果如何都打印「已取消所有已排定的关机」。这句话在修复前是假的，排查问题时容易被带偏。已改为准确描述。

### 升级方法

**直接替换 exe 即可。** 配置保存在 `%APPDATA%\AutoShutdownPro\config.json`，会自动沿用，不需要重新设置。

### 系统要求

Windows 10 / 11，**64 位**

### 首次运行提示

- **SmartScreen 会拦一次**：程序未做代码签名，点「更多信息」→「仍要运行」
- **杀毒软件可能误报**：PyInstaller 打包程序的常见现象，加白名单即可
