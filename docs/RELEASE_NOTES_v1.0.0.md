## 定时关机 v1.0.0

一个 Windows 定时关机小工具，带图形界面，用来替代「每天凌晨固定时间强制关机」这类硬编码脚本。

### 功能

- **快速定时**：30 分钟 / 1 小时 / 2 小时三个快捷键，或自定义分钟数（1 分钟 ~ 24 小时）
- **指定时刻**：今天或明天的任意 `HH:MM`
- **每天重复**：固定时刻每天触发，重启电脑后依然生效
- **到点确认窗**：置顶居中显示大号倒计时，随时可点「取消关机」；点右上角 ✕ 同样视为取消
- **五种动作**：关机 / 重启 / 睡眠 / 休眠 / 注销
- **系统托盘常驻**：关掉窗口不退出，托盘悬停即可看到剩余时间
- **暗色 / 亮色主题**：标题栏一键切换

### 使用方法

下载 `AutoShutdown-v1.0.0.exe` 双击即可，**无需安装 Python 或任何依赖**。

（GitHub 的 Release 附件名不接受中文，所以打包出来的文件用的是英文名。下载后你想改成「定时关机.exe」随便改，不影响运行。）

配置与日志保存在 `%APPDATA%\AutoShutdownPro\`，删掉该文件夹即可完全清除。

### 系统要求

Windows 10 / 11，**64 位**

### 首次运行提示

- **SmartScreen 会拦一次**：程序未做代码签名，点「更多信息」→「仍要运行」
- **杀毒软件可能误报**：这是 PyInstaller 打包程序的常见现象，加白名单即可
- 界面上「开机自启」默认开启，不需要的话取消勾选即可

### 关于可靠性的两点说明

- **关机 / 重启**会先把排程交给操作系统，再弹出确认窗。即使程序卡死或崩溃，到点系统依然会执行关机——不会出现「以为设了结果没关」
- **睡眠 / 休眠 / 注销**没有系统级的排程接口，由程序内计时执行；程序若在倒计时期间退出，动作不会发生（偏安全的方向）
